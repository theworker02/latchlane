# latchlane

Latch validation gates for lane inputs before they hit prod.

**Site:** https://theworker02.github.io/latchlane/

## Install / run

```bash
git clone https://github.com/theworker02/latchlane.git
cd latchlane
node src/cli.js
node --test
```
